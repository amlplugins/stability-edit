# @amlplugins/stability-edit

Native `stability-ai` SDK re-exported under the `@amlplugins` namespace.

> Stability AI Edit — erase, inpaint, outpaint, search-and-replace, search-and-recolor, remove background.

## Install

```bash
npm install @amlplugins/stability-edit
```

## Use

```ts
import { /* named exports from stability-ai */ } from "@amlplugins/stability-edit";
// or
import sdk from "@amlplugins/stability-edit";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
